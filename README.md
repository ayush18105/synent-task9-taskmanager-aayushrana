Full Stack Task Manager

 Description

A Full Stack Task Manager Web Application built using Python Flask. The application allows users to manage daily tasks efficiently with features like task creation, updating, deletion, user authentication, admin dashboard, and data export.

 Features

* User Registration
* User Login & Logout
* Create Tasks
* Update Tasks
* Delete Tasks
* Mark Tasks as Completed
* User Profile Management
* Admin Dashboard
* Export Tasks to CSV
* Session Management

 Technologies Used

 Frontend

* HTML
* CSS
* Bootstrap

 Backend

* Python
* Flask

 Database

* SQLite

Installation

 Clone Repository

```bash
git clone https://github.com/ayush18105/synent-task8-taskmanager-aayushrana.git
```

 Move to Project Directory

```bash
cd synent-task8-taskmanager-aayushrana
```

 Install Dependencies

```bash
pip install -r requirements.txt
```

 Run Application

```bash
python app.py
```
